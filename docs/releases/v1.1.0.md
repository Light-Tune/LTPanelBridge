# LT Panel Bridge v1.1.0

The first public GitHub Release of LT Panel Bridge provides the local companion
application used by supported LightTune Project Zomboid mods.

## Highlights

- Added English, Turkish, Spanish, Brazilian Portuguese, Russian and Simplified
  Chinese web-panel interface languages.
- English is used by default; the selected language is stored in the browser.
- Improved the three-column layout so panels remain inside the browser window.
- Removed the long layout instruction from the page header.
- Added local Discord webhook configuration for supported notifications.
- The bridge listens on `127.0.0.1` and does not expose the panel to the local
  network by default.

## Installation

1. Download `LTPanelBridge.zip` below.
2. Extract the ZIP to a permanent folder.
3. Install Node.js 18 or later.
4. Double-click `start-lt-panel.bat`.
5. Open `http://localhost:4242`.

LT Panel Bridge is a separate companion application and must not be copied into
the Project Zomboid `mods` directory.

## Verification

The release includes `LTPanelBridge.sha256`. Windows users can verify the ZIP
with:

```powershell
Get-FileHash .\LTPanelBridge.zip -Algorithm SHA256
```
