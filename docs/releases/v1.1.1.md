# LT Panel Bridge v1.1.1

This is the first public GitHub Release of LT Panel Bridge, the local companion
application used by supported LightTune mods for Project Zomboid Build 42.

## Highlights

- Added a browser-based administration panel at `http://localhost:4242` for
  supported LightTune features.
- Added complete interface languages for English, Turkish, Spanish, Brazilian
  Portuguese, Russian and Simplified Chinese.
- English is the default language; language and panel-layout preferences are
  stored locally in the browser.
- Reworked the three-column layout with balanced left and right margins and
  contained panel/table overflow for narrow and wide browser windows.
- Replaced overlapping panel refresh timers with one coordinated polling cycle.
- Prevented unchanged player, damage-log, permanent-death and market-tier
  tables from being rebuilt, eliminating visible text flicker.
- Language changes now trigger one complete redraw without losing the selected
  language, panel sizes or column positions.
- Removed the long layout instruction from the page header.
- Added local Discord webhook configuration for supported notifications.

## Privacy and security

- The bridge listens on `127.0.0.1` by default and is not exposed to the local
  network or the internet.
- Game state and commands stay inside
  `%UserProfile%\Zomboid\Lua\LightTune\`.
- No telemetry or remote LightTune account is used.
- No `npm install` step is required; the application uses only built-in Node.js
  modules.

## Installation

1. Download `LTPanelBridge.zip` from the Assets section below.
2. Extract the ZIP into a permanent folder.
3. Install [Node.js 18 or later](https://nodejs.org/).
4. Install and enable LightTune Lib and the supported LightTune Workshop mods.
5. Double-click `start-lt-panel.bat`.
6. Open `http://localhost:4242` in your browser.
7. Join Project Zomboid with an administrator account and open LT Settings.

LT Panel Bridge is a separate companion application. Do not copy it into the
Project Zomboid `mods` directory.

## Updating

Stop the previous bridge, extract the new ZIP into a clean folder and run
`start-lt-panel.bat` again. Project Zomboid saves and LightTune game data are
not stored inside the application folder.

## Verification

The Release includes `LTPanelBridge.sha256`. Windows users can verify the ZIP
from PowerShell:

```powershell
Get-FileHash .\LTPanelBridge.zip -Algorithm SHA256
```

Compare the displayed hash with the value in `LTPanelBridge.sha256`.

## Requirements

- Windows 10 or later
- Node.js 18 or later
- Project Zomboid Build 42
- LightTune Lib and at least one supported LightTune mod
- A Project Zomboid administrator account for administrative features
