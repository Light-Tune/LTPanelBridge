# Security Policy

## Supported version

Only the latest LT Panel Bridge release receives security fixes.

## Reporting a vulnerability

Please do not publish credentials, Discord webhook URLs, personal paths, or
working exploit details in a public issue. Contact the LightTune maintainer
privately first, include the affected version, and provide the minimum steps
needed to reproduce the problem.

LT Panel Bridge binds to `127.0.0.1` by default. Do not expose port 4242 to the
internet or forward it through a router or public reverse proxy.
